# 🍲 JD's Kitchen — Authentic Malabar Dum Biryani & Mandi (Kozhikode)

A cinematic, modern digital web application for **JD's Kitchen**, located in Parambath, Paloramala, Kozhikode, Kerala.

![JD's Kitchen Hero](https://jdskitchen.vercel.app/images/jds_beef_biryani_review.jpg)

---

## 🌟 Key Features

* **🍲 Culinary Dum-Cooking Preloader**: Multi-stage SVG preloader featuring an animated clay handi, smoldering coconut charcoal coals, wafting steam, and authentic Malabar kitchen status messages.
* **✨ 3D Taste Radar Pentagons**: Interactive 3D flavor pentagons mapping spice level, ghee richness, aroma, smoky wood-pit flavor, and meat tenderness for signature dishes.
* **📍 Interactive Tactical Google Map**: Built-in travel distance pills (*Kozhikode Railway Station: 18km, Calicut Airport: 32km, Cyberpark: 14km*) with direct 1-tap Google Maps navigation.
* **📷 Official Instagram Feed**: Live social gallery powered by `@jdskitchen.official` featuring real food moments, timber courtyard dining, and daily dum reveals.
* **💬 Real Google Maps Diner Reviews**: Authentic verified customer feedback paired with distinct, unique local dish & courtyard photos (no duplicated images).
* **📱 1-Tap WhatsApp Ordering**: Smooth slide navigation to direct WhatsApp kitchen counter ordering.
* **⚡ Edge Security & SEO Ready**: Pre-configured `vercel.json` edge security headers, OpenGraph link preview cards, and `schema.org/Restaurant` JSON-LD Google Search snippets.

---

## 🛠️ Technology Stack

* **Core**: React 18, HTML5, JavaScript (ES6+)
* **Styling**: Tailwind CSS (Dark Mode & Glassmorphism)
* **Animations**: Framer Motion & HTML5 3D Ember Particle Canvas System
* **Icons**: Lucide React & Official Vector SVG Logos
* **Hosting / Edge**: Vercel Edge Network

---

## 🚀 Deployment Instructions

### Deploy to Vercel (1-Click)

1. Push this repository to **GitHub**.
2. Import the repository into [Vercel](https://vercel.com/new).
3. Vercel automatically detects `index.html` and deploys to a global `.vercel.app` URL!
